# 🔧 tinker-log

> Things I figured out, so future me doesn't have to.

Welcome to **tinker-log**, a growing collection of how-tos, fixes and
"aha!" moments from whatever I happen to be tinkering with. Sometimes
that's code, sometimes it's a screwdriver, and occasionally it's both
at the same time (not recommended).

## What's this about?

Pretty much anything I had to figure out the hard way. If it took me
an afternoon, three forum threads and a cup of coffee too many, it
probably ends up here, written down clearly enough that next time it
takes five minutes.

## Why?

Because "I'll definitely remember how I did this" has never once been
true. These notes started as reminders for myself. If they save you
some time too, that's a win for both of us.

## Fair warning

Everything here worked for me, on my setup, on that particular day.
Your results may vary. Read before you run, back up before you break,
and measure twice before you cut, both in the workshop and in the
terminal.

## Spotted something?

Mistakes, better solutions or outdated steps: issues and pull requests
are always welcome.

## Adding an entry

1. Create a folder under the matching category, e.g. `diy/repairs/dishwasher-pump/`.
2. Copy [_template.md](_template.md) into it as `README.md`.
3. Put photos and screenshots in an `images/` subfolder.
4. Add a link to the entry list above.

Larger entries are split into numbered step files: the `README.md` is the
overview, and each step lives in its own `01-…md`, `02-…md` file based on
[_template-step.md](_template-step.md). See
[Ubuntu on a MacBook Pro (2015)](it/linux/ubuntu-on-macbook-pro-2015/README.md)
for an example.
